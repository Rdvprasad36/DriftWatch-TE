Experimental Methodology & Verification

DriftWatch-TE measures the security drift of hosted LLM endpoints interacting with a deterministic mock customer-service environment across 12 consecutive weeks.

  • Deterministic Goal Predicates (FR4): Attack success and task success are computed purely via world state invariant checks. No LLM judge is utilized.
  • Immutable Bundles (FR7): Weekly runs are stored as append-only Parquet bundles with SHA-256 hashes and published to Hugging Face Datasets.
  • Statistical Pre-registration (FR8): Longitudinal drift estimated via Logistic Generalized Estimating Equations (GEE) clustered by scenario with Benjamini-Hochberg FDR correction.
  • Zero-Cost Open Science (FR2, FR6): Executed entirely within free-tier quotas using GitHub Actions scheduled workflows.
