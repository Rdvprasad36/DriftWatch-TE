Research Design & Metric Definition

This evaluation runs identical frozen attack scenarios against hosted model endpoints every week under controlled temperature and deterministic world-state goal predicates. Attack Success Rate (ASR) measures the percentage of trials where an indirect prompt injection payload induced unauthorized state changes (e.g. fraudulent order cancelation or shipping address redirection). Longitudinal change is tested via Logistic Generalized Estimating Equations (GEE) with scenario clustering.

Test Your Own Model in 10 Minutes

Any OpenAI-compatible or local endpoint can be benchmarked against the identical frozen test suites. 

# 1. Clone repository and set up environment
git clone https://github.com/driftwatch-te/driftwatch.git
cd driftwatch
python -m venv .venv && source .venv/bin/activate
pip install -e .

# 2. Verify frozen suite integrity
driftwatch verify

# 3. Run pilot evaluation on your model endpoint
export LOCAL_MODEL_URL="http://localhost:11434/v1"
driftwatch run --week 2026-10-26 --suites canary,attacks_v1 --models local
